# Log

One file per month (`log/YYYY/YYYY-MM.md`), one entry per week, newest at the top. Each week has two parts in the same entry: the **Monday plan** and the **weekend report**. Copy from [`templates/weekly-report.md`](../templates/weekly-report.md). [`templates/log-entry.md`](../templates/log-entry.md) is the same shape.

The weekend report is required. A week with hours and a prototype but no report is not done.

Five to fifteen minutes on Sunday is enough for the report if the numbers are already in the terminal scrollback.

Do not put FlexTrade (or any employer) code, specs, configs, traces or numbers here. Work assignments: lesson only.

After week 13, add the specialization choice to that week's report. After each finished SI project, note it in that week's report and update [README.md](../README.md) status.
