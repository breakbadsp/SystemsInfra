# Log

One file per month (`log/YYYY/YYYY-MM.md`), one entry per week, newest at the top. Use [the log template](../templates/log-entry.md). Five minutes on Sunday is enough.

At the end of each quarter, add a short review to that quarter's last month: what got done, what slipped, what changes in the [roadmap](../ROADMAP.md).
