# Notes

Concept notes in my own words, one file per topic, named `<track-number>-<topic>.md`. Start from [the note template](../templates/note.md).

A note is worth writing when I can explain the topic without the source open. If I can't yet, it isn't ready. End each note with 3 to 5 quiz questions (see the loop in [`tracks/00-foundations.md`](../tracks/00-foundations.md)). The week's knowledge check in the [roadmap](../ROADMAP.md) can reuse those questions.
