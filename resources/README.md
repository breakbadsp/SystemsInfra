# Resources

One file per week, named `week-NN-<subject>.md`. Each file lists the sources given for that week's steps, in reading order. For each source, include a one-line note on what it is for and roughly how long it takes.

Each file starts with a short **Why it matters and where it is used** section. Learn the why and the applications before studying and building.

Future weeks get the same treatment: add a file here when the week's sources are set, then link it from the matching section in [`ROADMAP.md`](../ROADMAP.md).
